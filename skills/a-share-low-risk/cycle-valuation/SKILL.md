# 周期/资源股估值 Skill

## 目的
为有色、煤炭、油气、化工等商品周期股建立**低风险买点估值**，不是计算牛市情景下的理论最高价值。

核心原则：
1. 先还原**中性商品/成本水平下的正常化盈利中枢**；
2. 再判断未来6–18个月周期位置；
3. 再用保守估值倍数计算理论公允参考；
4. 最后用公司自身**180日市场价格分布**校准安全买入区与合理买入区；
5. 当前商品价格越强，不能机械地把低风险买入价越抬越高。

这恢复此前的定价框架：**盈利中枢 + 周期位置 + 分段估值 + 历史价格校准 + 安全边际**。

## 适用
有色、煤炭、油气、化工及其他利润与商品/价差高度绑定公司。机器锚配置见 `config/cycle_valuation_policy.json`；未来6–18个月结构化周期状态见 `config/cycle_regime_registry.json`。

## 固定依赖链
1. 识别主要利润来源及商品/价差暴露；多商品公司必须给主次/权重。紫金矿业必须同时看黄金与铜，不能只看单一铜价。
2. 获取当前年度与下一年度一致预期EPS，构建Forward-12m一致预期代理。**一致预期只是输入，不是最终盈利锚。**
3. 获取主要商品/成本锚优先约504个交易日、至少252个交易日历史，计算较长周期中性价格（默认长期窗口中位数）。禁止用单个高景气年份本身重新定义“中性商品价格”。
4. 将当前商品售价高于中性价格、或关键成本低于中性价格形成的周期超额利润从Forward一致预期中剥离，得到`normalized_forward_eps`。如果当前商品条件偏弱，不得反向机械抬高正常化盈利。
5. 读取结构化6–18个月周期状态：供给恢复/新增产能、需求趋势、库存、政策/地缘扰动，并建立bear/base/bull盈利情景。
6. 当前商品相对MA60的短期强弱只用于近端风险诊断：
   - 明显走弱可以继续下修低风险盈利；
   - 明显走强**不能**抬高低风险买入区，避免追着商品价格上调价值锚。
7. 根据当前周期阶段选择版本化合理估值倍数，得到`scenario_fair_value_range`和`normalized_base_fair_value_floor`。这些是理论情景参考，不直接等同买点。
8. 读取公司自身本地180日复权收盘价：
   - **安全价格候选：默认180日最低价～P10**，代表过去半年最极端的低成本区域；
   - **合理价格候选：默认P10～P60**，但不是无条件接受整个区间；
   - 合理买入上沿不得高于正常化基本面公允下沿经过宏观不确定性折价后的上限；
   - 同时不得显著高于MA60（默认最多MA60×1.06）。
9. 最终输出：
   - `safe_buy_range`
   - `reasonable_buy_range`
   - `value_anchor_range`
   都是**低风险价格锚**。
10. 原来的“Bear EPS×低倍PE ～ Bull EPS×高倍PE”必须单独命名为`scenario_fair_value_range`，不得继续叫“价值锚”，防止把牛市理论上沿误解为合理买价。

## 为什么需要180日价格校准
历史K线不决定企业内在价值，但能回答：
- 市场过去半年在哪些价格反复形成真实成本；
- 当前模型是否因为盈利预测或商品价格上涨而追着行情抬高买点；
- 基本面安全边际与市场承接区是否形成共振。

安全区故意使用180日最低价至P10，而不是P15-P35：对于已经经历明显上涨的周期股，整个分布会向上漂移；如果把分布中部当“安全区”，仍然会追着行情抬高安全买点。

如果理论估值明显高于180日市场成本中枢，则低风险买入区必须优先保持保守；如果理论估值已经低于历史低成本区，则由基本面估值主导，不能为了迎合历史价格强行抬高。

## 电解铝特别规则
- 必须同时看铝售价与氧化铝成本。
- 必须显式纳入未来供给恢复、库存重建和需求正常化风险。
- “当前铝价高、氧化铝成本低”属于周期超额利润来源，应先从一致预期中做正常化，而不是直接提高价值锚。
- 如果市场因未来复产/供给过剩预期而压低Forward PE，必须先判断预期是否合理，再区分预期差和低PE陷阱。

## 铜矿/黄金特别规则
- 铜价、金价处于高位时，一致预期EPS可能具有明显顺周期性。
- 铜/金当前价格强势只能提高盈利兑现置信度，不能直接提高低风险买入区。
- 紫金矿业等多商品公司先按商品利润贡献权重构建中性化盈利，再进入周期与价格校准层。

## 宏观不确定性
商品周期股受全球需求、美元/利率、地缘、库存迁移与政策影响。若没有独立、可验证的宏观方向模型，不允许用主观宏观判断直接提高估值；低风险系统通过正常化盈利、6–18个月周期Registry、宏观不确定性折价和180日市场价格锚保留安全边际。

## 输出
- `cycle_tag`
- 当前年/下一年一致预期EPS与增长
- `forward_12m_eps_proxy / forward_eps_weights`
- `normalized_forward_eps / neutralization_factor`
- `commodity_anchors`（含长期中性商品价格）
- `cycle_regime / cycle_regime_summary / cycle_regime_evidence / cycle_regime_scores`
- `short_term_anchor_effect_on_eps / low_risk_short_term_effect_on_eps`
- `bear_base_bull_regime_factor`
- `bear_base_bull_forward_eps`
- `reasonable_multiple_range`
- `scenario_fair_value_range`
- `normalized_base_fair_value_floor`
- `market_price_anchor_180d`
- `price_calibration_method`
- `value_anchor_range`
- `safe_buy_range / reasonable_buy_range`
- `invalidation_condition / valuation_status`

## 硬规则
- 资源股正式估值必须同时有当前年与下一年一致预期盈利；缺下一年盈利时不得用当前高利润替代。
- 一致预期不能直接作为低风险盈利中枢；资源股必须先做长期中性商品/成本正常化。
- 资源股正式估值必须有未过期的6–18个月周期Registry；过期或缺失则显式`unavailable`。
- 正向短期商品价格强度不得抬高低风险买入区；明显转弱可以下修。
- 资源股正式低风险买入区应读取本地180日历史价格；历史不足时允许退回纯估值安全边际，但必须显式标记。
- Bear/Bull理论估值包络不得再直接作为`value_anchor_range`。
- 若关键行情接口、一致预期、中性商品历史确实不可得，可输出`unavailable`，但必须记录具体数据缺口。
- 进入周期股左侧研究后不能因为计算复杂而跳过处理。
